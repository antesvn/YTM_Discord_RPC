YTM Discord RPC

Instalação

1. Extraia todo o conteúdo do arquivo ZIP para uma pasta do computador.
2. Abra o Brave e acesse brave://extensions.
3. Ative o Modo do desenvolvedor.
4. Clique em Carregar sem compactação e selecione a pasta extension que foi extraída.
5. Abra o Discord para computador.
6. Execute server\dist\YTM_Discord_RPC_silent_v6.exe com um duplo clique.

Se iniciar o executável antes do Discord, ele tentará se conectar novamente a cada 5 segundos.


Uso

- Reproduza uma música em music.youtube.com com a extensão instalada.
- A atividade do Discord mostra a música, o artista e o progresso.
- Ao pausar ou parar a música, a atividade é removida.
- Para encerrar o servidor, finalize YTM Discord RPC pelo Gerenciador de Tarefas.

Problemas

- Confirme que o Discord para computador está aberto e que a extensão está ativada em brave://extensions.
- Se houver erros, consulte server.log na pasta principal extraída, ao lado das pastas extension e server.
